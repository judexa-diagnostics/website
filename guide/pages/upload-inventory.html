Where

Add › Other ways to add. On a phone: IMEI batch scan, Non-serialized batch scan, Create new device. On a computer also: Search product, Create new product, Supplies and CSV import.

IMEI batch scan

  1. Scan IMEIs with the camera, or paste them into Paste IMEIs: commas, spaces and new lines all work.
  2. Add to the list. A typo, a repeat or a box label is kept out before anything is sent; the list says what it left out.
  3. Each phone is checked the usual way once it's in the cart. Give grades and prices, then save.

Non-serialized batch scan

For items you keep by quantity (cases, chargers): scan or paste their barcodes (UPC or EAN). The same barcode again adds one more. Not in your catalogue yet? Create item right there.

CSV import (computer)

  1. Make a CSV file (UTF-8) with one column named IMEI, Serial, UPC, Barcode or Code, one value per row. Header names aren't case-sensitive.
  2. Add › CSV import › pick the file › Add CSV to cart.
  3. Review the cart: Batch details sets who you bought them from (for every line) and where they go. Then save.

Spreadsheet files (XLSX, ODS) aren't read here: save the sheet as CSV first. Example file:

IMEI
356781234567890
356781234567891

To set buy prices for many models at once, a manager uses Import Prices (Basics and up). Prices you set always win over the starting list.
