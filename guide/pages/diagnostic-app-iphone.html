Install it on the phone

When the card says Install the inphox app: on the iPhone open the App Store and search “inphox”, install it, and keep the phone plugged in. The station pairs it by itself the moment it is there, waits for the result, then removes it.

A phone that was set up at the station gets the app the same way.

Pair it by hand

  1. In the phone's grading window on the lot: Diagnostics › Pair device. It shows a QR code and a 6-character code.
  2. On the phone you're buying, open the inphox app (sign in the first time), scan the QR code or type the code.
  3. Follow the tests on screen. Results show up live under Diagnostics.

Code stopped working? Press Pair device again. The Get the app button on the lot screen and on Station phones shows the App Store code: hover to see it, click to keep it open.

Results

Failed or skipped tests go into Notes / Issues when Write Diagnostic Results Into Notes is on (My Settings). The app's Face ID / Touch ID result wins over the station's (Biometrics).

It doesn't pair or doesn't report

  1. Keep the phone unlocked with the app open on screen.
  2. Check the phone has internet (Wi-Fi) and the station is signed in.
  3. Press Pair device again and scan the new code.
  4. Still nothing: grade it yourself. Nothing blocks the purchase.
