iPhone: Trust This Computer

  1. Unlock the iPhone before or right after you plug it in.
  2. It asks Trust This Computer? Tap Trust.
  3. Type the phone's passcode to confirm.

Didn't see the question? Unplug, unlock the phone, plug it back in. On the lot, press I Have Trusted This Phone once you've done it. Tapped Don't Trust by mistake? Unplug and plug in again: it asks again.

Android: allow USB debugging

  1. Unlock the phone and plug it in.
  2. If USB debugging is off: Settings › About phone › tap Build number 7 times, then Settings › Developer options › USB debugging on.
  3. The phone asks Allow USB debugging? Tap Allow. Ticking Always allow from this computer saves the step next time.

On some phones the menu names differ slightly (Software information, System › Developer options); the steps are the same.

A new station

Trust belongs to the computer: on a different station, phones ask again.

Before the phone leaves

An erase removes the trust and USB debugging along with everything else.
