Download it

On home.inphox.net: account menu › Help & downloads. The Double Puff download is a link made just for you that works once; open it on the computer the phones will plug into. The page shows the download for that computer first (Windows or Mac).

Windows

  1. Run the Double Puff installer you downloaded. Approve the admin prompt.
  2. It installs Double Puff in your own user folder and opens it. From then on it checks for a new version each time it starts.
  3. Keep the installer: it is also how you open Double Puff again if you close it. Never run anything else from its folder.

Mac

  1. Open Double Puff from the download.
  2. Opened straight from the installer, it says it is running from the installer. Press Move to Applications: it copies itself there and reopens.
  3. From then on, open it from Applications. A copy run from anywhere else can't update itself.

Sign in at the station

  1. Top right: Sign in. The window says Sign in to inphox; sign-in opens in your browser.
  2. Use the account your shop added you with. The station then shows your email under Settings › Account with Signed in on this PC.
  3. The station feeds the lots that this same person has open on the Intake website.

Log out or switch account from your name at the top right.

Read the lot line

Connected, waiting for an active lot (amber)Fine: open a lot on the Intake website.
Active lot … (green)The lot you have open on the website. Phones you plug in now go into it.
No active lot (grey)Not signed in, or offline.

Leave it on

Double Puff sits in the tray (Windows) or the menu bar (Mac) and starts by itself when you sign in to the computer, so it's ready every morning. On Windows it starts through the installer, which first puts in any new version. On a Mac it is a login item (System Settings › General › Login Items).

Which version

The version is at the bottom of the app and under Settings › About, together with the station's name, for example Double Puff 1.10.32 · Windows. Include both when you report an issue. Keeping it current: Updates.
