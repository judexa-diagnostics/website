Where

Double Puff › Settings › Phone Wi-Fi. It says which network phones set up here will join, for example Phones set up here join "Shop-5G", the network this computer is on.

Automatic

With nothing typed in, phones join the network this computer is on. If the station can see the network but not its password, it says so: This computer is on "…", but its password could not be read yet. Type it below so phones can join. A computer on a cable, not Wi-Fi, says This computer is not on Wi-Fi.

Type a network in

  1. Type the Network name and the Password. Leave the password empty for an open network.
  2. Press Use this network. It says Saved. Phones set up here join "…" (sent within 15 seconds).

The password is saved on this PC only. Use this computer's Wi-Fi goes back to automatic.

When it's used

When the station sets up an iPhone at the Hello screen (Auto activate) or after an Erase and activate, the phone joins this network so it can be activated and checked. Use a network with internet access and no sign-in page.

Who can change it

A manager or the owner. Staff see the setting but the station refuses the change.
