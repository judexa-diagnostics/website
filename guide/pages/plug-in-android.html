A phone that is already set up

  1. Unlock the phone, then plug it in. Newer phones turn off USB while locked.
  2. Turn on USB debugging if the card asks: Settings › About phone › tap Build number 7 times, then in Developer options turn on USB debugging.
  3. Tap Allow on the phone (Allow this computer). The station installs the inphox test app, opens it, waits for the result and removes it, with no more taps.

The card says Testing while it runs: keep the phone plugged in.

A phone at the Welcome screen

  1. Tap an empty spot on the Welcome screen 6 times. The phone opens its camera to scan a setup code.
  2. Scan your shop's inphox agent QR code. The inphox agent runs the tests and, if you ask for it, the erase. It never removes a Google account lock (FRP).

Already set up instead? Use the steps above (USB debugging).

The phone isn't answering

  1. Unplug the cable and plug it back in.
  2. Unlock the phone; if it asks, tap Allow.
  3. Still the same: try another cable or USB port, or type the details in with Manual on the lot.

"This computer can't open the phone"

The phone is there but this computer isn't allowed to open it over USB. Unplug and plug it back in. Still the same: whoever set up the station needs to give the computer USB permission for phones. Until then type the details in.
