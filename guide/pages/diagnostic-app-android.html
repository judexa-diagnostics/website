How it gets on the phone

  • A phone that is set up: once USB debugging is allowed (Allow this computer), the station installs the app, pairs it, opens it, waits for the result and removes it, with no taps.
  • A phone at the Welcome screen: tap an empty spot 6 times and scan your shop's inphox agent QR code. The agent runs the tests (and the erase, if you ask for one).

The card says Testing while it runs: keep the phone plugged in. The app removes itself when the result is in.

Where the results go

Live, under Diagnostics in the phone's grading window on the lot. Failed or skipped tests go into Notes / Issues when Write Diagnostic Results Into Notes is on (My Settings); a real failure is a red flag either way.

It doesn't open or doesn't report

  1. Keep the phone unlocked and the screen on until the test starts.
  2. Unplug the cable and plug it back in; tap Allow if it asks.
  3. On the station card, Retry scan.
  4. Still nothing: grade it yourself and note what you tested by hand. Nothing blocks the purchase.

Pair it by hand

In the grading window: Diagnostics › Pair device shows a QR code and a 6-character code. Open the inphox app on the phone, scan the code (or type it) and follow the tests on screen. Code stopped working? Press Pair device again.

Locks

The app never removes a Google account lock (FRP). A locked phone is reported as locked.
