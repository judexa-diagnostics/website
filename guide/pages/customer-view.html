Completely optional. Nobody has to run intake with the customer watching; you can do the whole lot on your own screen and they sign there.

Pair the tablet

  1. On the tablet open /customer-view on the Intake website. It shows Customer Station and a box for a code. Bookmark it.
  2. On the lot: top bar Customer View. A 6-letter code and a QR appear.
  3. Type the code and press Pair Station, or scan the QR. Display connected. It stays paired for 4 hours.
  4. The customer watches each phone go from Scanning to Determining Value to Value Set.

The whiteboard

Top bar Whiteboard, or the Board tab when grading one phone. Pick phones and photos under Available Devices › Import Selected, circle the cracks, write the price, then Send to Customer. Close hides it again.
