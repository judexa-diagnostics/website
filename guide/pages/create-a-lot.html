Every lot, at a glance

  1. Open the lot on the Intake website and keep that screen open (below).
  2. Plug the phones into Double Puff: unlock, Trust, passcode; wait for ✓ Device verified (iPhone, Android).
  3. Grade and price each phone; saving prints the label (Grade and price).
  4. Erase them if you want (Secure erase), then add the customer and sign (Add the customer, Bill of sale).
  5. ⋮ › Sync to Cloud: the phones are in your shop (Send to your inventory).

Start the lot

  1. Sidebar › New Intake. The Lot ID fills itself in. Leave it.
  2. Printer: Connect › USB Connection or Bluetooth Connection. Only the first time; after that it reconnects by itself.
  3. Wait for four green ticks: PDF Template, Lot ID, Store, Operator. A red one says what to fix.
  4. Start Lot. With Auto-Start Lot on, it starts itself after 3 seconds. Double Puff now says Active lot.

Keep the lot open

Double Puff adds phones to a lot only while you're on that lot's screen and using it, signed in as the same person as the station. A lot nobody has open never takes phones.

Leave or close itAbout 25 seconds after you close the tab or go to another page, intake stops: the station goes back to Connected, waiting for an active lot. Open the lot again from My Lots and it starts again.
AwayAnother tab for a few minutes is fine. Hidden for 5 minutes, or no mouse, keyboard or touch for 15 minutes, and the screen says Intake paused: you've been away. Press Resume. Scanning a barcode counts as using it.
Two lots openThe one you clicked into last gets the phones.
