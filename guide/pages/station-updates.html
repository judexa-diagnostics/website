The update strip

When inphox releases a new version, a strip appears above the phones: Update available: 1.10.32 · Download & restart · Later. Nothing installs by itself.

  1. Download & restart. It downloads, then says Ready: restarts when no phone is connected.
  2. It waits until every phone is unplugged, so nothing is cut off mid-read or mid-erase, then restarts into the new version, still signed in.

Later hides it until the next check (about every half hour) or the next time the app opens. Don't put it off for days: every station should run the same version.

Windows

Each time Double Puff starts through its installer it puts in any new version first. With the computer set to start it at sign-in, that happens every morning.

Mac

Always run it from Applications: run from the installer it can't update, and the strip says to move it first. Check for Updates… in the app menu checks now. An older copy in Applications is replaced only after you press Replace.

Check the version

At the bottom of the app and under Settings › About. Every station should show the same number.
